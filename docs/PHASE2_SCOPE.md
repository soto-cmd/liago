# LiaGo — Fase 2

Esta rama prepara el núcleo comercial antes del único despliegue a producción.

## Alcance

- Clientes y cuenta corriente
- Categorías, productos y servicios
- Código interno, SKU y código de barras
- Proveedores
- Stock por sucursal e historial de movimientos
- Ventas contado, parcial y crédito
- Deudas y cobros
- Compras
- Caja y gastos
- Reportes y dashboard
- RLS multiempresa y roles
- Numeración por empresa
- Operaciones transaccionales mediante RPC

## Regla de entrega

No fusionar a `main` ni desplegar Vercel hasta completar revisión, migraciones, validación de seguridad y build.
